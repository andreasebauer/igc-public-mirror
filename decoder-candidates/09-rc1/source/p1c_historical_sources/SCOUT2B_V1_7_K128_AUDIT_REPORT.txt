2. WHAT THE CORE THEOREM REALLY SAYS
====================================

For each local constituent site v, Q retains:

  p_v = exact seven-port counter vector
  u_v = exact reservation vector

and forgets exact edge pairing/topology and T.

An external cross attachment reads only:

  one local (p,u) color from side A,
  one local (p,u) color from side B,
  one endpoint type on each side,
  the frozen Bridge predicate.

It increments one coordinate of u on each selected site. Hence:

  - legality depends only on Q;
  - the successor Q depends only on Q;
  - hidden T and edge pairing are not read;
  - the successor has the same Q schema.

This is a direct theorem from the frozen local semantics. The millions of V1.7
regression cases are implementation/adversarial evidence, not the logical
basis of the theorem.

Together with V1.6's corresponding theorem for RANK-LIFT and internal
RELATION-ADD, this gives exact Q-observable substitution by structural
induction for every FIXED finite operation/context tree.

5. NEW AUDIT FINDING — ⊙ IS NOT ASSOCIATIVE
============================================

V1.7 froze commutativity, closure and finite-context substitution, but it did
not test contraction/order independence.

The audit tested three genuine mature-node singleton Q objects with port
vectors:

  A = (62,7,4,0,0,1,41)
  B = (59,1,0,2,2,0,6)
  C = (48,1,0,2,2,1,14)

At Q level:

  |A⊙B| = 19
  |B⊙C| = 23

Then:

  |(A⊙B)⊙C| = 554 Q outcomes
  |A⊙(B⊙C)| = 600 Q outcomes

The sets are different:

  left-only  = 273
  right-only = 319

A separate exact materialization using full mature states and literal retained
edges reproduced the same projected-Q mismatch:

  exact left constructions:  824
  exact right constructions: 910
  projected Q left:          554
  projected Q right:         600
  Q sets equal:              NO.

So this is not a quotient bug. It is a property of the newly defined binary
"exactly one cross edge between the two operands" operation.

WHY:
A left bracketing requires an A--B cross edge to exist before C is attached.
A right bracketing requires a B--C cross edge first. Those are different
constraints on the final two-edge connected structure.

Important scope point:
This does NOT falsify V1.7's finite-context theorem. For any FIXED syntax tree,
exact-vs-Q substitution remains correct. What fails is the stronger statement
that arbitrary parenthesization/contraction order is behaviorally irrelevant.

That stronger property was central in the earlier closed finite algebra and
has not yet been earned here.


6. Q IS A MACRO BOUNDARY, BUT IT HAS NOT CONTRACTED TO A NEW ATOMIC LEVEL
========================================================================

For every legal external composition:

  |Q_out| = |Q_A| + |Q_B|.

Q therefore retains one anonymous local (p,u) interface site per constituent
mature node. It hides:

  - exact edge pairing/topology,
  - T,
  - node names/provenance,

but it does NOT hide the lower-level constituent interface-site granularity.
External attachment still selects one of those anonymous local colors.

This is perfectly compatible with the frozen phrase "structured macro
entity". It is NOT the same achievement as the O1 mature node's fixed local
16-counter exact boundary representation.

So the current hierarchy is better written as:

  exact relational interior
       -> distributed sufficient skin Q
       -> closed Q-observable external behavior

not yet as:

  many O1 nodes -> one new atomic O2 node.


7. EXACT IDENTITY VERSUS BEHAVIORAL IDENTITY
============================================

Q is not injective on exact O2 carriers. That is intentional and now well
verified: distinct T states and distinct typed incidence topologies can hide
behind the same Q.

Therefore phrases such as "exact substitution" must always be qualified:

  exact with respect to the projected Q-observable future interface behavior
  of the frozen operation algebra.

It is NOT exact reconstruction of the full O2 carrier identity.

This distinction is scientifically healthy, but it matters for graduation. A
future operation that reads T, path/cycle structure, edge pairing, deletion,
rewiring, geometry, or ancestry reopens the quotient immediately.
