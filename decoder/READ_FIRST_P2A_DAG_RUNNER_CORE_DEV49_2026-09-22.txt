1. RESULT

P2A adds the deterministic, fail-closed state machine for the compiled
L0-upward replay DAG. It verifies the V9 manifest, requires an empty dataset
root, schedules nodes in the compiler's canonical topological order, seals a
content-addressed checkpoint after every accepted node or workflow gate, and
resumes by verifying every stored hash before skipping completed work.

This is runner infrastructure only. It has no scientific handler bindings and
is not yet a registered controller/C6 root job. Those are P2B.

2. STOP AND RESUME CONTRACT

Manifest-declared historical replay outcomes continue automatically. Every
declared discrepancy outcome stops at the first affected node and emits one
compact audit capsule containing the exact manifest, run, node, dependency
frontier, result and evidence bindings.

External decisions are accepted only when their canonical hash and capsule,
run, node, result and evidence bindings all match. REPEAT reopens only the
stopped node. A missing historical authorization can be opened only by an
external CERTIFY_AND_ADVANCE decision, after which the scientific node still
has to execute and produce a result.

The runner never interprets earned algebra or creates its own authority.
