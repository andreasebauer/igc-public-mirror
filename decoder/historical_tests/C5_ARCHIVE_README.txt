Infinity Grid Decoder C5 historical test archive

These files are preserved verbatim from the accepted C5 transition parent.
They test pre-C5 invocation models in which unit tests directly created or
entered root execution/service contexts. C5 intentionally rejects those
invocation models. They are therefore excluded from the active C5 regression
inventory, not treated as passing final-architecture tests. Their historical
evidence remains available here and in prior accepted checkpoints.

This archival move changes test invocation scope only; G6 science is unchanged.
