HOST PREREQUISITES AND INSTALLATION
Before running install.sh: inspect the actual server, Linux/systemd version,
CPython 3.12, git, disk/memory/mounts, existing services, users and datasets.
Use a local POSIX filesystem supporting flock, fsync, atomic rename and hardlinks;
network filesystem behavior is unqualified. Verify native package hashes resolve
for the host platform; do not relax the requirements on installation failure.
Package downloads require the host's normal package-index access.

Run install.sh as root only after reviewing its exact commit and paths. It is a
fresh-install procedure and refuses an existing release/config/API unit. It
preserves an existing catalogue and contains no deletion commands. Failures leave
partial staging for inspection; there is no automatic cleanup or destructive retry.
Existing host deployments need an explicit migration review, not this fresh installer.

The installer fetches the exact commit, verifies source, creates both environments,
installs dependencies, creates private state directories and installs the units.
It reloads systemd definitions, but does NOT enable/start services. It finishes by
running host runtime/source/config readiness as igdecoder. A failure leaves the
installation unready. The generated API listens on 127.0.0.1:8765 only.

SERVICES
ig-decoder-api: authenticated API/UI; credential loaded through systemd
LoadCredential, not a command argument or environment variable. Access logging
is disabled to keep single-use download capabilities out of access logs.
ig-decoder-execution: long-running capture/run/checkpoint/export lane.
ig-decoder-control: independent cooperative pause lane.
ig-decoder-save: independent Drive transfer and native confirmation lane.
Workers receive no API credential directory or token. Drive access is configured
separately using the B4S3 server-managed private token file and its rotation process.

START/STOP AND RECOVERY
There is no service-imposed science runtime deadline. Units use RuntimeMaxSec and
TimeoutStopSec infinity, KillMode mixed, SendSIGKILL no. Normal operation is not
stopped by closing a browser. This configuration is not proof of device/disconnect
qualification; that remains B5S3/B6. Before upgrades or planned stops, use native
cooperative pause, wait for acknowledgement, save pending objects and inspect
worker state. Do not forcibly restart a service with active science children.
A main-worker failure may leave a native child running with the inherited lane
lock. Service restart must not replay it; existing queue reconciliation applies.
Do not edit/delete native locks, request rows or ambiguous evidence to force start.
