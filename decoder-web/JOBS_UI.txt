Status boundaries
Jobs list labels distinguish Web request, Registered job and Native record.
Run requested is not proof of Running. Finished is not scientific PASS.
The selected job only reports running activity when native status reports a busy
workspace and a matching running job record, and labels this as a report.
An idle workspace with an old RUNNING record needs reconciliation.
Backup remains Unknown in the list until separately inspected; it is never
inferred from completion. The detail says Native reports preserved only when
native capture/outbox observations show no pending objects/checkpoints and
PRESERVED. This is a native report, not an independent remote-save audit.
A completed pause request does not hide an active run request.
